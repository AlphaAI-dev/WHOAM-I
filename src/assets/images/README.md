# Images

Put the site's images here. They are found automatically by base name
(see `src/config/assets.ts`):

| Base name | Used for | Suggested size |
|---|---|---|
| `portrait` | Opening scene, 3:4 frame | ≥ 1200 × 1600 px |
| `founding-tree` | Founding Tree illustration | ≥ 2000 px wide, transparent PNG or WebP works best |

Keep the original (`.jpg` / `.png`) and optionally add a `.webp` with the
same base name; the site serves the WebP and falls back to the original.
